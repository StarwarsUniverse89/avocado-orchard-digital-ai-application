# Avocado Orchard Digital AI Application

## Overview
This project is a high-performance AI agent system that simulates and analyzes avocado orchards using real and synthetic data.

It combines:
- Digital twin visualization
- AI agent decision-making
- GPU-accelerated inference on AMD infrastructure

## Key Features
- Interactive orchard map + digital twin
- Scenario simulation (weather, moisture, pests)
- AI agent for actionable recommendations
- Model inference powered by AMD GPUs
- Scalable architecture for real-world deployment

## Architecture
- Frontend: Next.js (UI + visualization)
- Backend: FastAPI (API + simulation engine)
- AI Agents: Prompt-based + model-driven (Qwen/Llama)
- ML Layer: AMD GPU-powered inference & training

## AMD Integration
- Uses AMD Developer Cloud for model inference
- Designed for ROCm compatibility
- Scalable to GPU-accelerated workloads

## Goal
Transform agricultural data into real-time, AI-driven decisions using high-performance compute.
