# AI Digital Twin Agent for Avocado Orchard

## Overview

This project builds an AI-powered digital twin for avocado orchards that combines:

- Real-time simulation (biological + environmental)
- AI decision-making (agent-based)
- Economic impact modeling (yield + profit)
- GPU-accelerated visualization (AMD MI300X)

Unlike traditional dashboards, this system provides a **living, interactive model** where users can:

- See current orchard conditions
- Simulate decisions (irrigation, harvest timing)
- Visualize outcomes in real-time 3D
- Understand financial impact instantly

---

## Architecture Layers

1. Data Layer (research + synthetic orchards)
2. Simulation Layer (rule-based + GPU-ready models)
3. AI Agent Layer (decision + reasoning)
4. Economics Layer (yield → revenue → profit)
5. Real-Time Layer (WebSocket streaming)
6. Visualization Layer (3D digital twin)
